# GitHub Actions Course 🚀

A hands-on repository to learn GitHub Actions through practical exercises, real-world examples, and reusable workflows.

## 📚 Contents
- Workflow basics
- CI/CD pipelines
- Reusable workflows
- Secrets & environment variables
- Deployment examples

## 📁 Structure
- `examples/` – sample workflows  
- `exercises/` – practice tasks  
- `solutions/` – reference solutions  
- `.github/workflows/` – workflow definitions  

## 🚀 Getting Started
1. Fork or clone this repository  
2. Explore the `exercises/` directory  
3. Run workflows and experiment  
4. Compare your results with `solutions/`
